# 去 AI 味层：检测、分级与改写纪律（中英文）

版本：v1，2026-11-11 新建。来源：
- lieflat-less-ai-tone（larashero3-dotcom，GitHub；两轮 1,169 篇、约 520 万汉字的生成与人类对照语料，配对复测）：工作流、分级、改写纪律、证据分层；
-本体系writing_spec 第 7—10 轮英文引言盲判实验（`source_materials/writing_spec_products/AI_TRACES.md`、规则卡 v6 §6—7、写手笔记）；
- 示例稿修订中用 Zotero 中文顶刊 35 篇、英文顶刊 225 篇做的语料核对。

**定位**：本层是质量检查，不是规避检测的工具。目标是让稿子读起来像本领域顶刊作者写的；判断依据是本领域顶刊语料，不是通用文体。

## 1. 改写纪律（硬约束，高于本层其他条目）

1. **最小改动**：只改命中条目的最小范围，其余逐字保留。
2. **信息守恒**：不新增、不删除事实、数字、名字、日期、出处、因果、限定词（"可能""通常"）。改后每个实词都能在原文找到出处，找不到就撤销。
3. **结构不动**：标题层级、节与段的顺序、表、公式不因去 AI 味而改。结构问题另走结构审读。
4. **不制造参差**：不为了"像人"去打乱句长、加口语、加错字，也不把任何指标推向目标值。
5. **拿不准就保留原文**。
6. **作者的写法优先**：有作者已裁决的措辞或作者本人风格样本时，以之为准。
7. **先报告，后改写**：未经作者回复，不动原稿（与协议 D1 一致）。

## 2. 工作流

1. **检测**（只报告）：脚本或逐段扫描本层 §3、§4 的条目，记录次数、密度、原文例句。
2. **复核**：逐条判断是否真命中，排除豁免情形（§3 末尾、§5）。
3. **分级报告**，等作者回复：

| 级 | 含义 | 处理 |
|---|---|---|
| A | 机械改，零语义风险（如解释性冒号改句号） | 给出改法，作者确认后改 |
| B | 需句式重组（如翻案句、宣布式过渡） | 逐条给改法，作者确认后改 |
| C | 整篇级问题（如全文句长过匀、分节过碎） | 只报告，作者要求时再处理 |
| H | 人审区，模型判不准（比喻是否贴切、语气是否合适） | 默认保留，列清单供作者看 |
| X | 已否决，语料证据不支持改 | 永不改，只展示计数 |

4. **改写**：按作者回复执行，每处改动对应一个条目编号。
5. **复测**：重扫一遍，给出前后对比；确认数字、引文、限定词零改动。

报告里每条写明：次数或密度、参照语料、原文例句、改法、不改的理由。"研究语料中显著"不等于"这一篇有问题"，要看本篇实际密度。

## 3. 中文条目（学术文体校准版）

lieflat 的 11 条白名单原本把学术文体排除在适用范围外。下表是按经管中文顶刊语料逐条校准后的执行口径。

| # | 条目 | 学术稿执行 | 级 | 依据 |
|---|---|---|---|---|
| Z1 | 翻案腔"不是……而是……""没有……而是……" | 改为直接陈述正面判断 | B | lieflat 第一层跨模型证据；本体系禁令 |
| Z2 | 结论提示冒号、空引导冒号（"核心在于：""差异来自……："） | 改为句号或逗号加关联词；列举、公式、问句、标签冒号保留 | A | lieflat 第一层；中文顶刊引言冒号中位数 3 处，以列举为主 |
| Z3 | 顿号罗列过密（一个分句里三项以上） | 必要清单（变量、样本、条款）豁免；修辞性罗列压缩 | B | lieflat |
| Z4 | 相邻句同构（同一骨架、同样逗号数连用） | 改一句的结构 | B | lieflat 第三层弱信号，命中才改 |
| Z5 | 破折号用于戏剧性揭示 | 学术稿极少出现；出现则改逗号或句号 | A | lieflat；超过每千字 2 次优先处理 |
| Z6 | 概括覆盖已有具体数据（"显著提升"放在已有数字的位置） | 把具体数字移到该位置；不编造数据 | B | lieflat |
| Z7 | 段首零主语评论（非首段以评价开头、无回指）；段首用代词而无唯一所指 | 补一个回指词（"这""这一结果"）；段首不用代词 | A | lieflat 第三层 |
| Z8 | 衔接过顺、每句都有关联词；用连词掩盖缺失的推理 | 删掉不承担逻辑的关联词；删词再读法见 structure.md §5.5 | B | lieflat 第一层 |
| Z9 | 宣布式句子（只预告下一点、只说某事重要） | 删，或直接写那一点本身 | B | 英文盲判 B8、写手笔记 L2 |
| Z10 | 复述（同一结果、同一定义说两遍） | 每个事实说一次 | B | 英文盲判 B1（34/72） |
| Z11 | 防御性插入语（"需要说明的是""诚然""退一步讲""值得注意的是""需要关注的是""本文并不声称""这并不意味着""不可否认"） | 删 | A |本体系禁令；"值得注意的是"对应英文规则卡禁用的 It is worth noting |

**学术稿中不作为改写目标的（语料核实）**：
- 前置长定语：中文顶刊约 1 万句中占 14.3%，高于 示例稿的 8.0%。
- 句首"当……时"：每千句 5.2 次。
- 句首"因此，""然而，""此外，"：句首"因此，"每千句 32 次。
- "这意味着"式承接：lieflat 第四层已否决项。
- "对于……来说"话题框架：lieflat 列入翻译腔，学术稿中尚未做语料核对；单段密集出现时作 B 级个案报告。
- 被动、名词化、长句本身。

以上只有在同一段内密集重复、读起来别扭时，才作为 B 级个案报告。

## 4. 英文条目（来自英文顶刊引言盲判实验）

判官区分原文与生成稿依靠的线索（`AI_TRACES.md`），按出现次数排序：

| # | 生成稿的问题 | 写法 |
|---|---|---|
| E1 | 复述：主结果、数据、被引文献说两次以上（34/72） | 每个事实说一次；路线图前不写复述段 |
| E2 | 机械罗列渠道、文献、检验（27/72） | 用逻辑连接（because, so, by contrast），不逐项罗列 |
| E3 | 一句塞三个以上发现（13/72） | 两项相关发现可用对比连接；三项以上拆开 |
| E4 | 笔记体：碎句、标签、单元格名（12/72） | 只写完整句 |
| E5 | 理论或方法前置，问题和答案延后（11/72） | 先问题和答案预览，再长篇理论或方法 |
| E6 | 句子长短一致、整齐的主谓宾 | 自然混合；多数 18—32 词，每段至多一句 12 词以下 |
| E7 | 自我标注（"This is the paper's main finding"） | 让证据承担强调 |
| E8 | 过度断言（"unambiguously"） | 动词强度与设计匹配 |
| E9 | 段首"搭台"、段尾总结 | 段首直接给内容，段尾停在最后一条内容上（规则卡 §7） |
| E10 | 口号句、对仗句（"X buys Y, and Y buys Z"） | 机制用一个完整解释句说一次 |
| E11 | 反射性对冲（"the interpretation requires care"） | 只在设计需要时对冲，每个论断至多一次 |
| E12 | 禁用词：delve, landscape, realm, intricate, tapestry, pivotal, underscore, nuanced, "It is worth noting", "Interestingly"；自称 novel | 删或换平实说法 |

| E13 | 长插入语或从句塞在主谓之间 | 拆成两句：先给结论，再交代数据来源 |
| E14 | 被动句滥用 | 改主动（we find / the results show）；被动只用三种场合：施动者不明、强调受事、摘要与方法论适度使用；中文稿不套用本条 |
| E15 | 比较级不完整（higher、lower、larger 不说与谁比） | 补出比较对象 |
| E16 | 否定叠加（not uncommon 再叠 not consider） | 改成一个主动陈述（researchers often overlook） |
| E17 | 代词指代不清（this / these / it / them） | 换成具体内容；段首不用代词；全文搜索这些词逐个确认所指 |
| E18 | 空洞的 ing 从句（..., highlighting the importance of ...） | 删掉；要强调就另起一句说明怎么重要 |

原文有、生成稿缺的（只在有材料时使用，不得编造）：作者自己的评价句（每篇一两句）；新概念分 2—4 步搭起来；紧贴抽象论断的具体例子；历史或制度叙述（之前 → 变化 → 现在）；理想实验的表述；文献织进论证、以作者作主语并说明其发现。

## 5. 已否决项（X 级：不作为改写依据）

- "首先/其次""一、二、三"编号（正文内）；"这意味着"式承接；"赋能""闭环"类黑名单词；"AI 堆精确数字"；概括替代具体信息的一般性指控。lieflat 配对复测显示这些方向不稳或相反。
- 句长变异、虚词或代词数量、名词重复：不作为单独改写依据。
- 学术稿里的英文 "is consistent with"：英文顶刊的常规写法，不删；中文稿的"与……一致"按中文语言层 §A 执行。

## 6. 局限

- 生成侧特征随模型迭代变化，频率数字只代表特定时点；破折号、分号等单模型指纹方向不一，先判断稿子像哪个模型再决定改法。
- 比喻是否贴切、句子参差是否自然，机器判不准，归 H 级。
- 本层的中文核对只覆盖经管顶刊，用于其他学科需重新核对。
