# 稳健性检验与识别检验

来源标注同 `structure.md` 开头说明。

## 篇幅与位置

- 英文 680—2,450 词；独立成章 31/178，作为结果章小节 40/178。中文 400—1,450 字，几乎都作为结果章的二级节（25/33）。【语料 §2—§3】
- 三种安置：独立成章、作为结果章小节（最常见）、下沉附录只留一句回指。按主识别的软肋多少选择。【22 篇】
- 放在机制之前：先立可信度，再讲机制。【22 篇】

## 组织顺序

按读者会先担心什么排序，不按"我先跑了什么"排：
1. 结果是否偶然（随机生效时点、安慰剂）；
2. 是否依赖特定设定（固定效应、聚类、加权）；
3. 是否由特殊样本驱动（样本可比性、排除主要处理州、样本期间）；
4. 是否有遗漏变量或同期冲击（州级趋势、同期州法）；
5. 是否有反向因果或竞争性解释。

依据：【导师 A30】。章首可用一段小节导引列出各小节检验什么（`structure.md` §5 类 ⑥），第一句以内容开头："基准结果表明，……。将这一变化归因于……需要两个条件：……。"【判例 C-21】

## 每项检验的写法

- **三件事写清**：要解决什么疑虑、为什么这个方法能解决、结果说明什么。【导师 A30】
- **段首先说目的**，从 concern 出发："为排除……，本文……"；"To address the concern that ..., we ..."。【导师 A31】
- **辩护段四拍**：威胁自陈 → 逐项拆解 → 检验背书（统计量）→ 确认结论存活；威胁与回应严格同序。【22 篇 模式二】
- **排除句要给动作**（剔除、换样本、安慰剂零效应），只说 unlikely 不算排除。【22 篇】
- **七步论证段**（问题重要时用）：Why → 联系现实 → 可能后果 → 重要性 → How → 结果 → 含义；不必七句，逻辑链完整即可。【导师 A32】
- 引言里常规检验合并为一句。【导师 A18】

## 句式

英文【语料 §7】【22 篇】：
- "To address the concern that ..., we ..."
- "To rule out that [alternative] drives our findings, we show that ..."
- "We conclude that [alternative] cannot account for ..."
- "The results remain similar when ..."
- 章首："In this section, we examine whether ..."（结果、稳健性、机制各节常见）

中文【语料 §7】：
- "为排除这一替代解释，本文……"
- "为此，本文参考……，……"
- "替换……/ 更换……后，……的估计系数仍……"
- "考虑到……，本文进一步……"
- "表 N 第（1）列显示，……"

## 自查

1. 检验顺序是否按读者疑虑排列。
2. 每项检验是否写清疑虑、方法、结论。
3. 有无只说"不太可能"而没有排除动作的句子。
