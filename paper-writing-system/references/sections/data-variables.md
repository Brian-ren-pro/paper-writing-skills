## 段落顺序

固定由简入深：分析层面 → 各数据库来源 → 样本期间 → 变量定义与度量 → 匹配拼接 → 筛选删除 → 最终样本 → 描述统计导读。【导师 A21】

数据源多时，按数据源逐个走"来源 → 变量构造 → 描述统计"三拍；数据章的小节顺序可以就是结果章的小节顺序。【22 篇】

## 写法规则

- **写来历与做法**：出处、构造、口径、分母写多；不承载论证的批次、地名、个别均值删去。变量"是什么"归制度章，"怎么算"归数据章。【导师 A22】
- **变量交代句式全篇统一**：要么"先参照谁、为何选，再怎么度量"，要么"先度量、后原因"，选一种贯穿全篇；参照文献点名到篇，且与其实际做法一致。度量是必须项，原因最多半句。【导师 A23】
- **变量定义句**："X 为……，若……则取 1，否则取 0"；"贷款期限为……的自然对数"。不写"：（1）……，以……衡量；（2）……"。【判例 C-17】【language/zh.md §E】
- **定义、构造、理由各一句**，不挤在一句里；两个因变量不在同一句里构造。【language/zh.md §E】
- **控制变量只讲它如何影响 Y**，绝不写它与处理变量相关。正当写法："地方经济条件可能同时影响信贷条件与合同设定，因此控制之。"【导师 A24】
- **数据卖点不抬级**：粒度、覆盖率如实写，引言与数据章数字一致。【22 篇】
- **测度构建型**：构造与验证不在同一节完成。【22 篇】
- **描述统计导读**：不逐格念表，只点与后文检验相关的分布事实；均值口径与正文经济显著性的基数一致。【22 篇】【sections/results.md】
- **样本规模数字**全文一致（借款人数、贷款数、批次数）。【sections/results.md §5】

## 句式

英文【22 篇】【语料 §7】：
- "Our primary analysis is based on [granularity] data from [source], covering [objects] from [period]."
- "After merging [A] with [B], the final sample consists of [N] [units]."
- "We obtain data on ... from ..."; "Following [Paper], we measure ... as ..."
- "Panel A of Table 1 reports ..."

中文【语料 §7】：
- "本文选取［时间］［对象］作为研究样本，数据来源于……"
- "参照［作者］（［年份］），本文以……度量……"（或 ZE："我们以……度量……"）
- "本文对样本进行如下处理：……最终得到……个观测值。"
- "表 1 报告主要变量的描述性统计。"

## 自查

1. 顺序是否由简入深；有没有跳来跳去。
2. 每个变量的交代句式是否统一；参照文献是否点名到篇。
3. 控制变量的表述有没有提到与处理变量相关。
4. 样本数字与摘要、引言、表格一致。
