# 实证设计与识别

来源标注同 `structure.md` 开头说明。

## 篇幅与位置

- 英文 800—3,200 词；独立成章的是少数（约 6/22、25/178），多嵌在数据章末或结果章首。【22 篇】【语料 §2】
- 中文多为"研究设计"章下的"模型设定"二级节，1,100—2,100 字（与数据合计）。【语料 §3】

## 段落顺序

1. 识别挑战：朴素做法的问题是什么。
2. 为何用现在的做法，其原理是什么（以堆叠 DID 为例：每个批次的首次处理单位，加窗口内干净的对照组，构成子样本，再堆叠回归）。
3. 方程。
4. 固定效应与聚类：每组固定效应吸收什么、留下什么变异。
5. 识别假设及其检验路径（平行趋势、预检验等），指向后文的检验。

依据：【导师 A25】【22 篇】。

## 写法规则

- **先白话、后方程，方程从简**：下标不必堆满，批次维度可以用语言交代；能删的括号删掉。【导师 A25】
- **识别写高不写细**：抽象层次要高、去技术化。【导师 A25】
- **基准模型段不掺稳健性内容**（加权、替代样本放稳健性章）。【导师 A25】
- **关键设定都要有"参照谁"**：聚类层级、变异来源、窗口长度。【导师 A25】
- **固定效应不只报名字**，要写清它吸收什么、留下什么。【22 篇】
- **IV / Bartik 先直觉后技术**：为什么需要 IV → 经济直觉 → 相关性 → 排他性 → 具体构造和估计结果。【导师 A26】
- **识别辩护落在可检验的事实上**（检验统计量、对照组构造），不落在形容词上；弱工具时主动降低因果语气。【22 篇】
- **公式**：用公式编辑器，通行符号，斜体，下标逗号分隔。【导师 A38】

## 句式

英文【22 篇】：
- "Identifying the effects of [X] on [Y] is challenging, as [threat]."
- "The main identification challenge we face is ..."
- "Batch × borrower fixed effects absorb ..., so the estimate comes from ..."
- "That is, the F-test on the instrument in the first stage is above [value], indicating that ..."

中文：
- "各州在不同年份分批实施……，本文的研究设计属于交错处理……"
- "具体而言，对每个处理批次，……；再将……个批次的子样本堆叠估计。"
- "模型控制……固定效应，估计量来自……"
- "其中，……为……；……为……。"（方程下的变量说明句）

## 自查

1. 方程之前有没有一段白话说清做法和原理。
2. 每组固定效应有没有写清吸收什么。
3. 基准设定段里有没有混入稳健性内容。
