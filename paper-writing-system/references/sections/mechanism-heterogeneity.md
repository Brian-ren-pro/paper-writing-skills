# 机制、渠道、异质性与拓展分析

来源标注同 `structure.md` 开头说明。

## 篇幅与位置

- 英文 740—2,280 词，独立成章 26/178、作为小节 22/178。【语料 §2—§3】
- 中文 2,500—4,300 字，约 20 段，多单独成章（24/33），是中文稿篇幅最重的章之一。【语料 §2—§3】
- 异质性章篇幅常不低于主效应章，因为它承担"预测逐项兑现"的验收功能。【22 篇】

## 段落顺序

1. 机制问题段（这一节回答"结果为什么出现"）。
2. 机制证据逐条：每条一个小节，逻辑一句 → 设定 → 结果 → 回扣机制。
3. 异质性按理论预测的维度逐项展开（维度在引言或理论章已预告，不临时发明）。
4. 竞争性解释在本章裁决。

依据：【22 篇】【导师 A33】。

## 写法规则

- **讲逻辑故事，不讲模型构造**：提出机制 → 预测"在 C 更强的样本中效应更显著" → 交互项或分组验证 → 结果回推机制，多个代理变量一致才下结论。"事前特征不随时间变化、主效应被固定效应吸收"这类构造话删或压到一句。【导师 A33】
- **机制收纳异质性**：异质性不只是切组罗列显著性；先提炼机制，用它组织异质性。机械的、可排除的异质性放稳健性；能讲故事的放机制章；不做纯一致性的异质性。【导师 A34】
- **章首总起**：先说明机制由哪几个来源构成，与理论章、引言的总起句用同一套措辞（如"公开化风险有两个来源：一是……，二是……"）。【判例 C-14】
- **代理变量对应构念**：每个代理变量先说它对应机制的哪一部分、为什么，再给结果；交互项只解释它对应的那一环。【判例 C-14】
- **不显著的维度也要解释**，且解释与前文理论一致（判例：担保在两类借款人中同等提高，解释为"担保决定违约后的受偿，不改变债权人相对其他债权人行动的先后"）。【判例 C-12】
- **拓展分析的过渡写出理由**："期限和担保在签约时一次确定，公开化的后果却在贷款存续期内逐步显现。"不写"同样的逻辑延伸至……"。【判例 C-11】
- **收束**：章末一句把各项证据合成一个判断（"这些证据表明，示例政策通过提高债权人面临的公开化风险影响债务契约"）。
- 对冲：机制推断默认"意味着/说明"级；"表明"照常使用，不降级为"指向"。【language/zh.md §A】

## 句式

英文【语料 §7】【22 篇】：
- "What can explain ...?"
- "If [mechanism], the effect should be stronger for borrowers with ..."
- "To test this, we interact [treatment] with ..."
- "Consistent with this prediction, ..."
- "Together, these findings suggest that ..."

中文【语料 §7】：
- "如果……通过……影响……，……应当在……的借款人中更强。"
- "为检验这一渠道，本文/我们在基准模型中加入……的交互项。"
- "表 N 第（1）列显示，交互项系数为……，在 5% 水平上显著。"
- "在此基础上，……"；"基于此，……"
- "综上，……"

## 自查

1. 每个机制检验有无先写预测、再给结果。
2. 机制总起句与引言、理论章是否一致。
3. 不显著维度的解释是否与前文冲突。
