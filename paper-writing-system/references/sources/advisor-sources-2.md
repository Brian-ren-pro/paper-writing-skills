## 1. 指导要点提炼（Y1–Y13）

**Y1 数据章由简入深、一件事说完再说下一件。** 固定顺序：先声明分析层面（贷款合同层面）→ 各数据库来源 → 样本期间 → 变量定义与度量 → 匹配/拼接过程 → 筛选与删除 → 最终样本。层级不能混，像剥洋葱一层一层；"每句话可能都对，但跳来跳去读者就丢了"。

**Y2 变量交代句式全篇统一。** 每个变量要么"先参照谁+为何选、再怎么度量"，要么"先度量、后原因"，选定一种贯穿全篇；参照文献必须点名到篇（不许只写"参照银行贷款文献"），且要与该文献的实际做法一一对上。变量小节只讲度量本身，想讲原因最多半句，度量是必须项、原因是锦上添花。

**Y3 红线：控制变量只能讲它如何影响 Y，绝不能写它与 X 相关。** 转写中点名旧稿一句"（州级经济变量）并可能与州级法律生效时间相关"必须删——写控制变量与处理变量相关，等于自曝共线性，会"引发审稿人质疑"。控制变量的正当表述是"地方经济条件可能同时影响信贷条件与合同设定，因此控制之"。

**Y4 识别策略先白话、后方程，方程从简。** 堆叠 DID 要先用一段话讲清：渐进 DID 有什么问题 → 堆叠的思路（每批次首次处理单位+窗口内干净对照组构成子样本 → 堆叠回归）→ 再给方程。方程下标不必四维堆满：队列维度可用语言交代、能删的括号删掉（参照文献多只写三维）；基准模型段不掺稳健性的东西（如加权处理放稳健性章再说）；关键设定（聚类层级、变异来源）都要有"参照谁谁谁"。

**Y5 机制检验要讲逻辑故事，不要讲模型构造。** 正确写法：提出机制 → 预测"在 C 更强的样本里效应更显著" → 用交互项/分组验证 → 结果回推机制（如公司治理机制就找四个代理变量、四种情形一致指向才下结论）。错误写法（旧稿被点名）：通篇"事前特征不随时间变化、主效应被借款人固定效应吸收"这类构造话——与机制逻辑无关，删或压到一句。

**Y6 基本面检验的出场框架是"预检验"，不是"替代性解释"。** 结果章第一部分必须为基准结果服务：先立主假设（法律只改变信息环境、不改变基本面，这是全文识别前提）→ 为验证这一前提先做预检验 → 再上基准结果。上来就说"排除替代性解释"，读者会反问"你的主解释是什么"——替代性解释是稳健性章的语言。

**Y7 基准结果段：一个变量说完再说下一个，系数与经济意义合并交代。** 不要第一段罗列全部系数、第二段统一讲经济意义来回跳；不显著的变量（利差、规模）同样要交代并解释其含义；段末收束回假设（"综合上述结果……支持假设一"），做到删掉任何一段都会明显缺一块。

**Y8 表必须自足，表题注是"本表用何法检验何问题"。** 单独读表要能知道：研究问题、方法、X 与 Y、各 Panel 与各列含义、括号与星号含义、样本区间。老师的原话：你的那不叫表描述、只是表注；正式读者看完引言直接看表，表看不懂文章就废了。英文稿表放文末单独成页。

**Y9 公式与排版范式。** 公式必须用公式编辑器（斜体、下标逗号分隔），只用通行符号（β、求和），不用生僻符号独树一帜——"目的在读者接受，不在与众不同"；公式里多余的固定效应项可删、正文语言交代；字体中文宋体、英文与数字 Times New Roman；不要用 WPS 交稿。

**Y10 句子层：主谓宾齐全、主动语态、最简词汇。** 每句必须有明确主语（制度背景里"诉讼成本降低"必须写清谁诉谁——此条在旧稿被重复提过两次）；引《经济学论文写作》的框架：留意读者已知/未知、先陈述所做再佐证最后与他人比较、被动语态通通换掉；不用深奥词，"让初中生都能听懂你在干什么"。

**Y11 读者意识与 callback。** 作者对自己文章太熟是最大误区：默认读者已忘前文，每节开头用最简洁的话 callback 动机与要点；每个部分既服务整体、又能被单独读懂（easy to follow 是顶刊文的隐形功夫）。自检三问：这段单独读能懂吗？删掉这句有影响吗（没影响就删）？和范文差在哪？写作前先设计"如何用最简逻辑分层分级把这件事说清"。

**Y12 参考文献十年断层警告（崔老师发现，孙老师复核）。** 旧稿参考文献只有 2025–26 年最新与 2015 年前经典，2015–2025 中间十年近乎空白——根源是让 AI 搜文献时只给了"最新+经典"两个指令。老师们的处置：补约十篇"贷款与法律"主题的近十年文章；更深层教训——没有 AI 的年代学生把近十年文献逐本读过，写到哪自然知道引什么，工具替代不了这一层积累。

**Y13 工作方法。** 每写一部分找 5–10 篇范文逐段对照（可让 AI 帮查差别）；先写中文捋顺逻辑、翻译只是翻译的事；修改次序先实证后前端（本轮从第 3 部分 data 起往后重过一轮，实证定了再定引言假设）；当前阶段定位是"大块已完、精雕细琢"。
