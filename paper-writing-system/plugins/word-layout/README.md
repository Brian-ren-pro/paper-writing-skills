# Word 排版插件（word-layout）

把稿件统一成指定的排版档案。流程阶段 7 使用（`references/workflow.md`）。依赖 python-docx 与 lxml。

## 用法

```bash
# 1. 只检查，报告偏差（不改文件）
python plugins/word-layout/docx_format.py check 稿件.docx --profile cn-workingpaper --out work/layout-report.md

# 2. 统一格式，输出新文件（原稿不动）
python plugins/word-layout/docx_format.py apply 稿件.docx 稿件_排版.docx --profile cn-workingpaper

# 3. 抽查：转 PDF 看标题、正文、三线表、图题、脚注、参考文献
soffice --headless --convert-to pdf 稿件_排版.docx
```

## 档案（profiles/）

| 档案 | 用途 | 来源 |
|---|---|---|
| `cn-workingpaper` | 课题组中文工作论文、交导师审阅（默认） | 中文工作论文交导师版实测 |
| `cn-journal` | 中文期刊投稿通用格式 | 通用模板，投稿前按目标期刊须知修改 |
| `en-submission` | 英文期刊投稿通用格式（双倍行距、表图文末） | 通用模板，投稿前按目标期刊作者指南修改 |

新期刊复制一份档案改数值即可。字段：
- `page`：纸张与页边距（厘米）。
- `latin_font`：西文与数字字体。
- `classes`：各类段落的格式，字段包括中文字体 `east`、字号 `size`（磅）、`bold`、对齐 `align`、行距倍数 `line`、段前与段后 `before` / `after`（磅）、首行缩进字符数 `indent_chars` 或厘米数 `indent_cm`、悬挂缩进 `hanging_cm`。
- `table`：三线表的线宽，单位为 1/8 磅（12 = 1.5 磅，6 = 0.75 磅）。

### cn-workingpaper 要点

| 类别 | 格式 |
|---|---|
| 页面 | A4；上下 2.54 cm，左右 2.5 cm |
| 题目 | 黑体 16 磅加粗，居中 |
| 摘要、关键词 | 标签黑体加粗，正文宋体 10.5 磅，1.25 倍行距 |
| 一级标题（1. 引言） | 黑体 14 磅加粗，段前 12 磅、段后 6 磅 |
| 二级标题（2.1） | 黑体 12 磅加粗，段前 6 磅 |
| 三级标题（2.2.1） | 楷体 12 磅，首行缩进 2 字符 |
| 正文 | 宋体 / Times New Roman 小四（12 磅），两端对齐，首行缩进 2 字符，1.5 倍行距 |
| 表题、图题 | 黑体 10.5 磅加粗，居中 |
| Panel 标签 | 宋体 9 磅加粗，左对齐 |
| 表注、图注 | 宋体 9 磅，两端对齐，单倍行距 |
| 表格 | 三线表：顶线与底线 1.5 磅，表头下线 0.75 磅；单元格 9 磅，首列左对齐、其余居中 |
| 参考文献 | 宋体 / Times New Roman 10.5 磅，悬挂缩进 0.74 cm，1.25 倍行距 |
| 脚注 | 宋体 / Times New Roman 9 磅 |

## 段落识别规则

不依赖 Word 样式，按文本特征识别：
- 第一个非空段落：题目；
- "摘要""关键词"开头：摘要、关键词；
- "1. ""2.1 ""2.2.1 "或"一、"开头且较短：各级标题；
- "参考文献 / References""附录"：参考文献标题，其后到下一个表、图或标题之前为参考文献条目；
- "表 N / 图 N / 附表 AN / Table N / Figure N"开头且无句号：表题、图题；
- "Panel X"：Panel 标签；
- 紧跟表格、图片或表题之后的段落，以及以"注：""资料来源：""本表""本图"开头的段落：表注、图注；
- "[此处插入……]"：占位行；
- 公式段落与"（1）"式编号行：不改动。

其余按正文处理。check 报告会列出被识别为正文的短段落，供人工核对是否应为标题或图注。

## 注意

- apply 只改格式，不改文字；改完后用 `scripts/run_checks.py` 复查，确认文字零改动。
- 写回作者本地前先确认作者已关闭该文件（protocol D8）。
- 表头行数靠"首个含两位以上小数的行"判断；表头结构特殊时，在报告里核对表头下线的位置。
